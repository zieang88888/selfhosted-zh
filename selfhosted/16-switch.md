# 16 · 常见商业服务 → 自托管替代对照

> 想离开某个 SaaS？先查这张表。每一行都是"你现在用什么 → 可以换成什么自托管"。

| 你在用的商业服务 | 自托管替代 | 说明 |
| --- | --- | --- |
| Dropbox / Google Drive / OneDrive | Nextcloud、Seafile、ownCloud | 私有网盘、同步、共享链接 |
| Google Photos / iCloud 照片 | Immich、PhotoPrism、Lychee | 手机自动备份、人脸/时间线 |
| Netflix / Plex 媒体库 | Jellyfin、Emby、Kodi | 自己的影音库，多端串流 |
| Spotify / Apple Music | Navidrome、Funkwhale、Koel | 自己的音乐流媒体 |
| YouTube | PeerTube | 联邦化视频托管 |
| Notion / Obsidian Sync | AppFlowy、AFFiNE、Trilium | 文档+数据库+白板 |
| Evernote / OneNote | Joplin、Logseq、Standard Notes | Markdown 笔记，可自建同步 |
| Trello / Asana | Vikunja、Planka、Focalboard、Plane | 看板/项目管理 |
| Google Docs / Office 365 | Nextcloud + Collabora / OnlyOffice | 在线协同编辑文档 |
| Miro / Figma 白板 | Excalidraw、tldraw | 手绘风无限白板 |
| Airtable | NocoDB、Baserow、Teable | 智能表格/低代码数据库 |
| Slack / Teams / Discord | Mattermost、Rocket.Chat、Revolt | 团队/社区聊天 |
| Zoom / Google Meet | Jitsi Meet、BigBlueButton | 浏览器视频会议 |
| Gmail / Outlook.com | Mailcow、Mailu、iRedMail | 自己的邮件服务器 |
| Mailchimp / ConvertKit | Listmonk、Mautic | 新闻信/营销邮件 |
| 1Password / LastPass | Vaultwarden、Bitwarden | 自托管密码库 |
| GitHub / GitLab.com | Gitea、Forgejo、GitLab CE | 私有代码托管 |
| Statuspage / UptimeRobot | Uptime Kuma、Cachet | 站点监控与状态页 |
| Datadog / Grafana Cloud | Prometheus + Grafana、Netdata | 自建监控告警 |
| Twitter / X | Mastodon、Misskey | 联邦式微博客 |
| Instagram | Pixelfed | 联邦图片社交 |
| Reddit | Lemmy | 联邦链接聚合社区 |
| Linktree | LinkStack | 链接聚合主页 |
| Cloudflare / ngrok 穿透 | frp、rathole、Tailscale/Headscale | 内网穿透/组网 |
| 商业备份服务 | Restic、Borg、Duplicati、UrBackup | 加密增量备份 |
| 百度网盘（对外分享） | Alist、Nextcloud、Pingvin Share | 自托管网盘/分享 |

> 注意：替代不代表"1:1 功能一致"。迁移前请先跑起来试用，确认协作、客户端、移动端体验满足需求再切。

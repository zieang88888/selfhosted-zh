# 05 · CMS 与博客

> 建站、博客、无头内容管理。替代 Medium / Wordpress.com / Notion 建站。

## 传统 CMS / 建站

- [WordPress](https://wordpress.org) — 全球占比最高的博客/CMS，插件生态无敌｜GPL-2.0
- [Ghost](https://ghost.org) — 专注出版/订阅的现代博客平台｜MIT
- [Joomla](https://www.joomla.org) — 成熟的通用内容管理系统｜GPL-2.0
- [Drupal](https://www.drupal.org) — 企业级灵活 CMS，开发者友好｜GPL-2.0
- [Strapi](https://strapi.io) — 最流行的开源无头 CMS，自助 API 构建｜MIT
- [Directus](https://directus.io) — 给任意 SQL 数据库套一层实时 CMS/API｜GPL-3.0
- [Payload CMS](https://payloadcms.com) — TypeScript 优先的现代无头 CMS｜MIT
- [Wagtail](https://wagtail.org) — 基于 Django 的开源 CMS｜BSD-3-Clause
- [Statamic](https://statamic.com) — 基于 Laravel 的紧凑 CMS（有开源版）｜MIT
- [OctoberCMS](https://octobercms.com) — 现代 Laravel CMS｜MIT
- [Craft CMS](https://craftcms.com) — 灵活的内容管理（核心开源）｜BSD-3-Clause
- [Grav](https://getgrav.org) — 无需数据库的扁平文件 CMS｜MIT
- [ApostropheCMS](https://apostrophecms.com) — 内嵌式可视化编辑的 CMS｜MIT
- [ModX](https://modx.com) — 灵活高效的 CMS/应用框架｜GPL-3.0
- [Textpattern](https://textpattern.com) — 轻量优雅的老牌文章发布系统｜GPL-2.0
- [WriteFreely](https://writefreely.org) — 极简、联邦化的长文写作平台｜MIT
- [Plume](https://github.com/Plume-org/Plume) — ActivityPub 联邦化博客引擎｜AGPL-3.0
- [Chyrp Lite](https://chyrplite.net) — 轻量的博客引擎｜BSD-3-Clause
- [Typecho](https://typecho.org) — 轻简优雅的中文博客系统｜GPL-2.0
- [Halo](https://halo.run) — 现代化开源建站工具，插件主题生态活跃｜GPL-3.0
- [Publii](https://getpublii.com) — 桌面端所见即所得静态博客编辑器｜MIT
- [WonderCMS](https://www.wondercms.com) — 单文件超轻量 CMS｜MIT
- [GetSimple CMS](https://get-simple.info) — 极简的 XML 文件型 CMS｜GPL-3.0
- [Pico](https://picocms.org) — 把 Markdown 文件变成网站的扁平 CMS｜MIT
- [Serendipity](https://s9y.org) — 老牌稳定的博客引擎｜BSD
- [b2evolution](https://b2evolution.net) — 自带论坛/邮件列表的博客 CMS｜GPL-2.0
- [KeystoneJS](https://keystonejs.com) — 基于 Next.js 的内容管理与应用框架｜MIT

## 静态站点生成器（SSG）

- [Hugo](https://gohugo.io) — 超快的 Go 静态站生成器｜Apache-2.0
- [Hexo](https://hexo.io) — 流行的 Node.js 博客静态生成器｜MIT
- [Jekyll](https://jekyllrb.com) — GitHub Pages 默认的 Ruby 静态生成器｜MIT
- [Zola](https://www.getzola.org) — 单二进制、快如闪电的静态生成器｜MIT
- [Eleventy](https://www.11ty.dev) — 简单的 JavaScript 静态站点生成器｜MIT
- [VitePress](https://vitepress.dev) — Vue 团队出品的轻量文档站生成器｜MIT
- [Astro](https://astro.build) — 面向内容的现代网站框架，默认零 JS｜MIT
- [VuePress](https://vuepress.vuejs.org) — Vue 驱动的静态文档站生成器｜MIT

# 11 · 在线协作（文档 / 白板 / 项目 / 网盘协作）

> 多人实时文档、白板、任务看板。替代 Google Workspace / Miro / Trello / Figma。

## 实时文档与白板

- [Etherpad](https://etherpad.org) — 多人实时协同编辑的富文本文档｜Apache-2.0
- [HedgeDoc](https://hedgedoc.org) — 实时协作 Markdown 文档｜AGPL-3.0
- [Outline](https://www.getoutline.com) — 团队文档协同（也见知识库篇）｜BUSL-1.1
- [Excalidraw](https://excalidraw.com) — 手绘风无限白板，可自托管｜MIT
- [tldraw](https://www.tldraw.com) — 现代无限画布协作白板｜Apache-2.0
- [WBO (Whiteboard)](https://github.com/lovasoa/whitebophir) — 简单的协作在线白板｜AGPL-3.0
- [Drawpile](https://drawpile.net) — 多人协同在线绘画画布｜AGPL-3.0
- [LibreOffice Online](https://www.libreoffice.org) — 在线版 LibreOffice，嵌入 Nextcloud 协同｜MPL-2.0
- [Collabora Online](https://www.collaboraonline.com) — 企业级在线 Office 套件｜LGPL
- [OnlyOffice](https://www.onlyoffice.com) — 功能最接近 Microsoft 365 的在线办公套件｜AGPL-3.0

## 项目 / 任务管理

- [Vikunja](https://vikunja.io) — 开源自托管待办/项目看板（可替代 Trello）｜AGPL-3.0
- [Focalboard](https://www.focalboard.com) — Mattermost 出品的开源看板（Trello 替代）｜AGPL-3.0
- [Planka](https://planka.app) — 美观简洁的看板项目管理｜AGPL-3.0
- [Taiga](https://www.taiga.io) — 敏捷开发项目管理平台｜MPL-2.0
- [OpenProject](https://www.openproject.org) — 企业级开源项目管理｜GPL-3.0
- [Plane](https://plane.so) — 现代开源项目管理（Jira 替代）｜AGPL-3.0
- [Wekan](https://wekan.github.io) — 类 Trello 的开源看板｜MIT
- [Kanboard](https://kanboard.org) — 极简看板项目管理｜MIT
- [Budibase](https://budibase.com) — 低代码内部工具/表单搭建｜GPL-3.0
- [Appsmith](https://www.appsmith.com) — 开源低代码内部应用搭建｜Apache-2.0
- [NocoDB](https://nocodb.com) — 把任意数据库变成 Airtable 般的智能表格｜AGPL-3.0
- [Baserow](https://baserow.io) — 开源无代码数据库/表格（Airtable 替代）｜MIT
- [Teable](https://teable.io) — 高性能开源多维表格（Airtable 替代）｜AGPL-3.0

## 其他协作 / 短链

- [Jitsi Meet](https://jitsi.org) — 视频会议（也见通讯篇）｜Apache-2.0
- [Nextcloud Groupware](https://nextcloud.com) — Nextcloud 内的日历/联系人/邮件协作｜AGPL-3.0
- [Shlink](https://shlink.io) — 自托管短链接服务｜MIT
- [Kutt](https://kutt.it) — 现代自托管短链接服务｜MIT
- [Yourls](https://yourls.org) — 经典 PHP 短链接系统｜MIT

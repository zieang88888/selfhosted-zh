# 09 · 邮件服务

> 自建邮件服务器、Webmail、新闻信/邮件营销。替代 Gmail / Outlook.com / Mailchimp。

## 一体化邮件服务器

- [Mailcow](https://mailcow.email) — Docker 化完整邮件栈，开箱即用，自托管邮箱首选｜GPL-3.0
- [Mailu](https://mailu.io) — Docker Compose 部署的完整邮件服务器｜MIT
- [iRedMail](https://www.iredmail.org) — 一键部署完整邮件解决方案｜GPL-3.0
- [Mail-in-a-Box](https://mailinabox.email) — 把 Ubuntu 变成开箱即用的邮件服务器｜CC0
- [Modoboa](https://modoboa.org) — 带 Web 管理面板的邮件托管平台｜ISCL
- [Poste.io](https://poste.io) — 一体化邮件服务器，免费版功能完整｜MIT
- [Maddy](https://maddy.email) — 单二进制、配置简单的现代邮件服务器｜MIT
- [Stalwart Mail Server](https://www.stalwart.email) — 用 Rust 写的现代邮件/目录/存储服务器｜AGPL-3.0
- [Postal](https://github.com/postalserver/postal) — 现代可扩展的邮件投递平台｜MIT
- [Citadel](https://www.citadel.org) — 一体化协作平台，含邮件/群件｜GPL-2.0

## MTA / MDA / 组件

- [Postfix](https://www.postfix.org) — 经典安全的邮件传输代理（MTA）｜IBM 许可
- [Dovecot](https://www.dovecot.org) — 主流 IMAP/POP3 邮件投递代理（MDA）｜MIT/LGPL
- [PostfixAdmin](https://github.com/postfixadmin/postfixadmin) — Postfix 的虚拟域 Web 管理面板｜GPL-2.0
- [Exim](https://www.exim.org) — 高度可配置的老牌 MTA｜GPL
- [Haraka](https://haraka.github.io) — Node.js 事件驱动的高性能 SMTP 服务器｜MIT
- [Rspamd](https://rspamd.com) — 现代反垃圾邮件过滤系统｜Apache-2.0
- [SpamAssassin](https://spamassassin.apache.org) — 经典开源反垃圾邮件过滤器｜Apache-2.0
- [ClamAV](https://www.clamav.net) — 开源防病毒引擎，常与邮件栈搭配扫毒｜GPL-2.0
- [Postgrey](https://postgrey.postfix.org) — Postfix 的灰名单策略守护进程｜GPL-2.0

## Webmail 客户端

- [Roundcube](https://roundcube.net) — 经典开源 Webmail 客户端｜GPL-3.0
- [SnappyMail](https://snappymail.eu) — 轻量快速的 Webmail，RainLoop 的活跃分支｜AGPL-3.0
- [RainLoop](https://www.rainloop.net) — 简洁现代的 Webmail 客户端｜AGPL-3.0
- [SOGo](https://sogo.nu) — 开源组件服务器，含 Webmail/日历/联系人｜GPL-2.0
- [Afterlogic WebMail](https://afterlogic.org) — 轻量 AJAX Webmail｜AGPL-3.0
- [Mailpile](https://www.mailpile.is) — 注重隐私与加密的 Webmail（项目趋缓）｜AGPL-3.0
- [Nextcloud Mail](https://github.com/nextcloud/mail) — 集成在 Nextcloud 里的邮件客户端｜AGPL-3.0

## 新闻信 / 事务邮件

- [Listmonk](https://listmonk.app) — 高性能自托管新闻信/群发邮件管理器｜AGPL-3.0
- [Mautic](https://www.mautic.org) — 开源营销自动化平台｜GPL-3.0
- [Mailtrain](https://mailtrain.org) — 自托管新闻信服务（项目趋缓）｜MIT
- [GNU Mailman 3](https://docs.mailman3.org) — 经典邮件列表管理系统｜GPL-3.0

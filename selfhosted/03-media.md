# 03 · 媒体与照片管理

> 影音播放、追剧追番、自动下载刮削、照片墙。替代 Plex / Netflix / Google Photos。

## 影音服务器与播放端

- [Jellyfin](https://jellyfin.org) — 完整免费的媒体服务器，转码/字幕/多端客户端齐全（可替代 Plex）｜GPL-2.0
- [Emby](https://emby.media) — 媒体服务器，核心开源、部分插件闭源｜GPL / 专有组件
- [Kodi](https://kodi.tv) — 老牌影院级媒体中心软件，跑在电视/盒子上｜GPL-2.0
- [Gerbera](https://gerbera.io) — UPnP/DLNA 媒体服务器，串流到电视｜GPL-2.0
- [Universal Media Server](https://www.universalmediaserver.com) — 基于 PS3 Media Server 的 DLNA 串流｜GPL-2.0
- [MiniDLNA (ReadyMedia)](https://sourceforge.net/projects/minidlna/) — 极简 DLNA 媒体服务器｜GPL-2.0
- [Stremio](https://www.stremio.com) — 媒体聚合追剧客户端（本体开源）｜开源
- [Navidrome](https://www.navidrome.org) — 轻量 Subsonic 兼容音乐流媒体服务器｜AGPL-3.0
- [Airsonic-Advanced](https://github.com/airsonic-advanced/airsonic-advanced) — 现代音乐流媒体服务器，Subsonic 兼容｜GPL-3.0
- [Funkwhale](https://funkwhale.audio) — 联邦式音乐分享与流媒体平台｜AGPL-3.0
- [Koel](https://koel.dev) — 简洁优雅的个人音乐流媒体｜MIT
- [Lyrion Music Server](https://lyrion.org) — 原 Logitech Media Server，多房间音乐系统｜GPL-2.0
- [Mopidy](https://mopidy.com) — 可扩展的音乐播放后端，接 Spotify/本地｜Apache-2.0
- [Ampache](https://ampache.org) — 老牌 Web 音乐/视频流媒体｜AGPL-3.0
- [Music Player Daemon](https://www.musicpd.org) — 轻量常驻音乐播放守护进程｜GPL-2.0
- [Snapcast](https://github.com/badaix/snapcast) — 多房间同步音频播放器｜GPL-3.0
- [Shairport Sync](https://github.com/mikebrady/shairport-sync) — 把旧设备变成 AirPlay 音箱｜GPL-3.0
- [librespot](https://github.com/librespot-org/librespot) — 开源 Spotify Connect 接收器｜MIT
- [Audiobookshelf](https://www.audiobookshelf.org) — 自托管有声书与播客服务器｜GPL-3.0

## 下载与自动化

- [qBittorrent](https://www.qbittorrent.org) — 开源 BT 下载客户端，Vuze/uTorrent 替代｜GPL-2.0
- [Transmission](https://transmissionbt.com) — 极简轻量的 BT 下载客户端｜GPL
- [Deluge](https://deluge-torrent.org) — 插件化 BT 客户端｜GPL-3.0
- [ruTorrent](https://github.com/Novik/ruTorrent) — rtorrent 的 Web 前端｜GPL-3.0
- [Flood](https://flood.js.org) — 现代美观的 rTorrent/Deluge/qBittorrent Web 前端｜GPL-3.0
- [Aria2](https://aria2.github.io) — 多协议命令行下载工具｜GPL-2.0
- [AriaNg](https://ariang.mayswind.net) — Aria2 的漂亮 Web 控制面板｜MIT
- [yt-dlp](https://github.com/yt-dlp/yt-dlp) — 强大的命令行视频/音频下载器｜Unlicense
- [MeTube](https://github.com/alexta69/metube) — yt-dlp 的 Web 前端，浏览器点选下载｜AGPL-3.0
- [Sonarr](https://services.sonarr.tv) — 自动追剧集、下载、整理（可替代TV订阅）｜GPL-3.0
- [Radarr](https://radarr.video) — 自动追电影、下载、刮削整理｜GPL-3.0
- [Lidarr](https://lidarr.audio) — 自动化音乐库管理与下载｜GPL-3.0
- [Readarr](https://readarr.com) — 自动化电子书与漫画管理｜GPL-3.0
- [Bazarr](https://bazarr.media) — 自动为影片下载匹配字幕｜GPL-3.0
- [Prowlarr](https://prowlarr.com) — 索引器管理器，统一喂给 *arr 家族｜GPL-3.0
- [Jackett](https://github.com/Jackett/Jackett) — 把各 PT 站转成统一 Torznab 接口｜GPL-3.0
- [FlareSolverr](https://github.com/FlareSolverr/FlareSolverr) — 绕 Cloudflare 盾的代理，供 *arr 使用｜MIT
- [Jellyseerr](https://jellyseerr.dev) — 媒体请求与订阅门户，对接 Jellyfin/Emby｜GPL-3.0
- [TinyMediaManager](https://www.tinymediamanager.org) — 本地媒体库刮削与重命名整理｜免费/商业版
- [tvheadend](https://tvheadend.org) — 自托管 IPTV/DVR 电视服务端｜GPL-3.0

## 照片管理

- [Immich](https://immich.app) — 高性能自托管照片/视频备份，手机自动同步（可替代 Google Photos）｜AGPL-3.0
- [PhotoPrism](https://www.photoprism.app) — 带 AI 识图的照片库与发现引擎｜AGPL-3.0
- [Lychee](https://lychee.org) — 简洁漂亮的 Web 相册，一键上传整理｜MIT
- [Piwigo](https://piwigo.org) — 老牌功能丰富的相册管理系统｜GPL-2.0
- [LibrePhotos](https://github.com/LibrePhotos/librephotos) — 带人脸识别/地图的自托管照片库｜MIT
- [Photoview](https://github.com/photoview/photoview) — 简单的家庭照片画廊｜GPL-3.0
- [Damselfly](https://damselfly.info) — 轻量快速的照片管理与 EXIF 检索｜GPL-3.0
- [Ente (自托管模式)](https://github.com/ente-io/ente) — 端到端加密照片，可自建服务器｜AGPL-3.0

# 01 · 入门指南：什么是自托管，怎么开始

> 从零到跑起第一个自己的服务。读完这一篇，你就知道自托管到底在干嘛、第一步该踩哪块踏板。

## 什么是自托管（Self-Hosting）

自托管，就是把原本跑在别人云上的服务——网盘、相册、笔记、影音库、密码库、聊天——搬回**自己掌握的一台机器**上运行：可以是家里一台小主机 / NAS，也可以是一台租来的 VPS。

它和"用 SaaS"的核心区别只有一句话：**数据和运行环境由你自己控制**。

- 你决定数据存在哪、备份几份、谁能看；
- 没有"公司倒闭/涨价/停服"导致全家桶数据说没就没；
- 不会被广告、追踪、算法推荐绑住；
- 但代价是：你要自己负责维护、更新、安全、出故障时自己修。

## 自托管适合谁

- 想把照片、文档、密码从大厂云里"拿回来"的隐私敏感者；
- 喜欢折腾、把"搭一套自己的数字生活"当爱好的 Homelab 玩家；
- 需要可控、可审计、可迁移基础设施的小团队 / 开发者；
- **不适合**：完全不想管服务器、图省事、7×24 小时不能断服的生产业务。

## 怎么开始：最短路径三步

### 第 1 步：选硬件 / 选机器

| 方案 | 适合场景 | 大致成本 | 备注 |
| --- | --- | --- | --- |
| 闲置旧笔电 / 迷你主机 | 纯内网、家用、学习 | 已有 | 耗电、噪音需考虑 |
| 成品 NAS（群晖/威联通） | 存储为主、要省心 | 2000 元起 | 系统封闭，Docker 可补 |
| DIY 装机（N100 / 小主机） | 性价比玩家 | 1000–2500 元 | Docker 生态最舒服 |
| 云 VPS（按年付） | 需要公网、不想搞家里宽带 | 几十到几百元/年 | 无本地大存储 |

> 新手建议：**先在一台你已经有的电脑上用 Docker 练手**，不要一上来就买硬件。

### 第 2 步：解决"怎么从外面访问"

1. **域名**：在任意注册商买一个域名（一年几十元），这是你服务的门牌号。
2. **DNS**：把域名 A/AAAA 记录解析到你服务器的公网 IP；用 Cloudflare 等免费 DNS 还能套一层 CDN/防护。
3. **端口映射 / 组网**：
   - 家里宽带：在路由器做端口转发（80/443 → 内网主机），或用 **frp / WireGuard / Tailscale / Zerotier** 组网；
   - 很多家庭宽带没有公网 IP，这时 **Tailscale / Zerotier 这类组网工具**是最省心的选择。

### 第 3 步：搭好"安全底座"再装业务

按下面这个顺序，别跳步：

1. **装 Docker / Docker Compose**：90% 的自托管服务都有官方镜像，一条 compose 就能起。
2. **上反向代理**：用 Nginx Proxy Manager / Traefik / Caddy 把多个服务统一收敛到 80/443，顺便自动签 HTTPS 证书（Let's Encrypt）。
3. **开 HTTPS**：公网暴露的服务一律强制 HTTPS，别用裸 HTTP 跑密码登录。
4. **做备份**：重要数据（配置、数据库、相册原件）至少 **3-2-1**——3 份副本、2 种介质、1 份异地。

## 家庭服务器 vs VPS：怎么选

- **家庭服务器（Home Server / NAS）**：
  - 优点：一次硬件投入、电费低、带宽大、数据物理在你家；
  - 缺点：需公网 IP / 组网、断电断网要自己处理、上行带宽常受限、噪音功耗。
- **VPS（云服务器）**：
  - 优点：固定公网 IP、稳定在线、开箱即有带宽；
  - 缺点：按月/年付费、存储小且贵、数据不在本地、极端依赖云厂商。
- **常见组合**：本地 NAS 存大文件 + 一台便宜 VPS 做反代 / 跑轻量公网服务，是很多玩家的折中方案。

## 安全基线（上线前务必过一遍）

- [ ] 关闭不必要的端口，只暴露反代的 80/443；
- [ ] 所有 Web 服务强制 HTTPS，开启自动证书续期；
- [ ] 改默认端口、改默认口令，管理员账号开二次验证（2FA / TOTP）；
- [ ] 系统和容器镜像**定期更新**，别让服务裸奔一年不升级；
- [ ] 数据库、配置文件**定时备份并定期做恢复演练**；
- [ ] 公网暴露的管理后台（如 Portainer）务必加访问控制，别直接裸奔；
- [ ] 重要服务前面套一层反代 + 访问白名单 / IP 限制。

# 04 · 笔记与知识库

> 个人笔记、双向链接、团队 Wiki。替代 Notion / OneNote / Evernote。

## 个人笔记

- [Joplin](https://joplinapp.org) — 开源跨平台 Markdown 笔记与待办，可自建同步服务（可替代 Evernote）｜AGPL-3.0
- [Joplin Server](https://github.com/laurent22/joplin) — Joplin 官方的自托管同步/服务端｜AGPL-3.0
- [Logseq](https://logseq.com) — 本地优先的大纲式双向链接笔记｜AGPL-3.0
- [Trilium Notes](https://github.com/zadam/trilium) — 层次化、可脚本化的个人知识库｜AGPL-3.0
- [AppFlowy](https://appflowy.io) — Notion 的开源替代，Rust+Flutter，可自托管｜AGPL-3.0
- [AFFiNE](https://affine.pro) — 文档+白板+数据表三合一的开源工作区｜MIT
- [Standard Notes](https://standardnotes.com) — 端到端加密极简笔记，可自托管服务端｜AGPL-3.0
- [Notesnook](https://notesnook.com) — 端到端加密、注重隐私的笔记｜GPL-3.0
- [SilverBullet](https://silverbullet.md) — 面向极客的可编程 Markdown 空间｜MIT
- [Obsidian](https://obsidian.md) — 强大的本地 Markdown 笔记，可配自建同步（非服务端）｜专有软件
- [Anytype](https://anytype.io) — 本地优先、端到端加密的 P2P 对象型笔记｜免费
- [Memos](https://usememos.com) — 轻量自托管"碎片笔记/个人微博"，极适合做书摘｜MIT
- [Laverna](https://laverna.cc) — Markdown 加密笔记（项目维护趋缓）｜MPL-2.0
- [TagSpaces](https://www.tagspaces.com) — 基于本地文件夹的标签化笔记/文件管理｜AGPL-3.0
- [Zim](https://zim-wiki.org) — 桌面端轻量个人 Wiki 笔记本｜GPL-2.0
- [Turtl](https://turtl.it) — 加密的笔记/书签/密码自托管空间｜GPL-3.0
- [Foam](https://foambubble.github.io/foam/) — VS Code 里的 Markdown 知识管理｜MIT
- [Dendron](https://www.dendron.so) — 基于 VS Code 的结构化笔记工具｜GPL-3.0

## 团队 Wiki / 知识库

- [BookStack](https://www.bookstackapp.com) — 简洁易用的文档/Wiki 平台，分层书籍结构｜MIT
- [Outline](https://www.getoutline.com) — 团队知识库，文档美观，可自托管｜BUSL-1.1 / 开源核心
- [Wiki.js](https://js.wiki) — 现代 Node.js Wiki，所见即所得编辑｜AGPL-3.0
- [MediaWiki](https://www.mediawiki.org) — 维基百科同款引擎｜GPL-2.0
- [TiddlyWiki](https://tiddlywiki.com) — 单文件非线性个人笔记/Wiki｜BSD
- [DokuWiki](https://www.dokuwiki.org) — 纯文本、无数据库的经典 Wiki｜GPL-2.0
- [XWiki](https://www.xwiki.org) — 企业级 wiki 与应用开发平台｜LGPL-2.1
- [Docmost](https://docmost.com) — 现代开源团队文档与 Wiki｜AGPL-3.0
- [Nextcloud Notes](https://github.com/nextcloud/notes) — 集成在 Nextcloud 里的 Markdown 笔记｜AGPL-3.0
- [mdBook](https://rust-lang.github.io/mdBook/) — 用 Markdown 写书/文档站的静态生成器｜MPL-2.0
- [MkDocs](https://www.mkdocs.org) — 用 Markdown 搭建项目文档站的静态生成器｜BSD

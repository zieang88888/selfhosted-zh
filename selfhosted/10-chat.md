# 10 · 聊天与通讯

> 团队 IM、视频会议、联邦式社交网络。替代 Slack / Discord / Zoom / Twitter。

## 团队即时通讯

- [Mattermost](https://mattermost.com) — 开源自托管团队协作聊天（可替代 Slack）｜AGPL-3.0
- [Rocket.Chat](https://www.rocket.chat) — 功能齐全的自托管团队聊天平台｜MIT
- [Matrix Synapse](https://matrix.org) — Matrix 协议的参考 homeserver，去中心化联邦 IM｜Apache-2.0
- [Dendrite](https://github.com/element-hq/dendrite) — Matrix 官方第二代轻量 homeserver｜Apache-2.0
- [Conduit](https://conduit.rs) — 用 Rust 写的轻量 Matrix homeserver｜Apache-2.0
- [Element](https://element.io) — Matrix 官方客户端，跨平台｜Apache-2.0
- [Zulip](https://zulip.com) — 话题分线式团队聊天，适合大讨论｜Apache-2.0
- [Revolt](https://revolt.chat) — 开源、可自托管的 Discord 替代｜AGPL-3.0
- [Wire](https://wire.com) — 端到端加密的安全通讯（有自托管版）｜AGPL-3.0
- [ejabberd](https://www.ejabberd.im) — 老牌高性能 XMPP 聊天服务器｜GPL-2.0
- [Prosody](https://prosody.im) — 轻量灵活的 XMPP 服务器｜MIT
- [MongooseIM](https://mongoose-im.com) — 高并发企业级 XMPP 服务器｜Erlang 开源
- [Movim](https://movim.eu) — XMPP 协议的 Web 社交平台｜AGPL-3.0
- [Conversations](https://conversations.im) — 优雅的开源 XMPP 安卓客户端｜GPL-3.0

## 视频会议 / 音视频

- [Jitsi Meet](https://jitsi.org) — 开源视频会议，浏览器直接开会（可替代 Zoom）｜Apache-2.0
- [BigBlueButton](https://bigbluebutton.org) — 面向在线教育的开源视频会议系统｜LGPL-3.0
- [LiveKit](https://livekit.io) — 开源 WebRTC 音视频实时通信框架｜Apache-2.0
- [mediasoup](https://mediasoup.org) — 高性能 WebRTC 流媒体 SFU｜ISC
- [Janus](https://janus.conf.meetecho.com) — 通用 WebRTC 服务器｜GPL-3.0

## 联邦式社交（Fediverse）

- [Mastodon](https://joinmastodon.org) — 最流行的联邦式微博客社交网络｜AGPL-3.0
- [Misskey](https://misskey-hub.net) — 功能丰富的日式联邦社交平台｜MIT
- [Pleroma](https://pleroma.social) — 轻量的 ActivityPub 联邦社交后端｜AGPL-3.0
- [Lemmy](https://join-lemmy.org) — 联邦式 Reddit 替代（链接聚合社区）｜AGPL-3.0
- [Pixelfed](https://pixelfed.org) — 联邦式图片社交（Instagram 替代）｜AGPL-3.0
- [PeerTube](https://joinpeertube.org) — 联邦式视频托管平台（YouTube 替代）｜AGPL-3.0

## 点对点 / 隐私通讯

- [Session](https://getsession.org) — 去中心化、匿名的端到端加密聊天｜GPL-3.0
- [RetroShare](https://retroshare.cc) — P2P 加密通讯与文件分享网络｜GPL-2.0

# 07 · 仪表盘与导航首页

> 浏览器打开就看到自己全部服务的导航首页，以及一套管理服务器的 Web 面板。

## 服务导航首页（Homepage）

- [Homepage](https://gethomepage.dev) — 极受欢迎的自托管导航首页，组件化对接各服务状态｜GPL-3.0
- [Dashy](https://dashy.to) — 高度可定制、带状态小部件的仪表盘｜MIT
- [Heimdall](https://github.com/linuxserver/Heimdall) — LinuxServer 团队出品的简洁应用导航｜MIT
- [Homarr](https://homarr.dev) — 现代化仪表盘，深度集成 Docker 与各服务｜MIT
- [Flame](https://github.com/pawelmalak/flame) — 轻量自起始页，极客友好｜MIT
- [Organizr](https://organizr.app) — 把所有自托管应用聚合到一个登录页｜GPL-3.0
- [Glance](https://github.com/glanceapp/glance) — 极简、配置文件驱动的仪表盘/起始页｜MIT
- [DashMachine](https://github.com/rmountjoy92/DashMachine) — 简洁的自托管应用导航面板｜MIT
- [Homedash](https://github.com/testdasi/homedash) — 现代家庭服务器导航仪表盘｜MIT
- [Strap.d](https://strap.d) — 轻量的浏览器起始页/导航页｜MIT
- [LinkStack](https://linkstack.org) — 自托管的"链接聚合页"（bio link，可替代 Linktree）｜AGPL-3.0

## 服务器 / 容器管理面板

- [Portainer](https://www.portainer.io) — Docker/Kubernetes 可视化管理面板｜Zlib
- [Dockge](https://dockge.kuma.pet) — 优雅的 Docker Compose 栈管理器｜AGPL-3.0
- [Runtipi](https://runtipi.io) — 应用商店式一键安装自托管服务｜GPL-3.0
- [1Panel](https://1panel.cn) — 国产现代化 Linux 服务器运维面板｜GPL-3.0
- [CasaOS](https://www.casaos.io) — 面向家庭用户的简洁 NAS/服务器系统｜Apache-2.0
- [YunoHost](https://yunohost.org) — 把任意 Debian 变成"一键装应用"的服务器操作系统｜MIT
- [CapRover](https://caprover.com) — 开源 PaaS，一条命令部署应用｜Apache-2.0
- [Webmin](https://webmin.com) — 老牌 Web 化 Linux 系统管理面板｜BSD-3-Clause
- [宝塔面板](https://www.bt.cn) — 国内流行的可视化服务器管理面板｜免费/专有
- [DockStarter](https://dockstarter.com) — 向导式 Docker 部署配置生成工具｜MIT
- [Coolify](https://coolify.io) — 自托管的 Heroku/Netlify/Vercel 替代｜AGPL-3.0
- [Dokku](https://dokku.com) — 轻量 PaaS，基于 Docker 的 Heroku 风格部署｜MIT
- [Pterodactyl](https://pterodactyl.io) — 游戏服务器管理面板｜MIT
- [JupyterHub](https://jupyter.org/hub) — 给多用户提供 Jupyter Notebook 的服务｜BSD-3-Clause
- [EasyEngine](https://easyengine.io) — 专为 WordPress 优化的服务器栈管理工具｜MIT
